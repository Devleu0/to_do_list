# TODO CLI 프로그램

간단한 커맨드라인 기반 TODO(할 일 관리) 프로그램입니다.
할 일을 추가하고, 목록을 확인하고, 완료 처리 및 삭제할 수 있습니다.

---

## 기능

* 할 일 추가
* 할 일 목록 확인
* 할 일 완료 처리
* 할 일 삭제
* JSON 파일로 자동 저장 (`todo.json`)

---

## 파일 구조

```
.
├── main.py
├── todo.json   # 실행 시 자동 생성
└── README.md
```

---

## 실행 방법

### 1. Python 실행

```bash
python main.py
```

---

## 사용 방법

프로그램 실행 후 아래 메뉴가 표시됩니다:

```
1. 추가  2. 목록  3. 완료  4. 삭제  5. 종료
```

### 기능 설명

| 번호 | 기능      |
| -- | ------- |
| 1  | 할 일 추가  |
| 2  | 목록 보기   |
| 3  | 완료 처리   |
| 4  | 삭제      |
| 5  | 저장 후 종료 |

---

## 사용 예시

```
1. 추가  2. 목록  3. 완료  4. 삭제  5. 종료
선택: 1
할 일 입력: 운동하기
추가 완료

선택: 2
0. [✘] 운동하기 (2026-03-30 14:00)

선택: 3
완료할 번호: 0
완료 처리됨
```

---

## 데이터 저장 방식

* `todo.json` 파일에 자동 저장됩니다.
* 구조 예시:

```json
[
  {
    "title": "운동하기",
    "done": true,
    "created_at": "2026-03-30 14:00"
  }
]
```

---

## 주의사항

* 번호 입력 시 숫자를 입력해야 합니다.
* 잘못된 번호 입력 시 오류가 발생할 수 있습니다.
* 프로그램 종료 시에만 저장됩니다.
